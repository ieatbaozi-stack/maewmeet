## 2. แถบขั้นตอน `/groups/[gid]`
วางใต้หัวกลุ่ม เหนือรายชื่อสมาชิก · เป็นการ์ดเดียว (`--surface`, ขอบ `--line`, `--radius-lg`)

### 2.1 สถานะ
- แต่ละขั้น: **เสร็จ** (ขั้น 1, 2, 4 ตามข้อมูลจริง) · **ขั้นถัดไป** (ขั้นแรกที่ยังไม่เสร็จ มีได้ขั้นเดียว) · **รอ** (ที่เหลือ)
- ขั้น 3 ไม่มีสถานะ "เสร็จ" เป็นลิงก์เสมอ; เป็น "ขั้นถัดไป" ได้เมื่อขั้น 1 และ 2 เสร็จแล้ว (ถ้าขั้น 4 ยังไม่เสร็จด้วย ขั้น 3 มาก่อนตามลำดับ)
- **ครบ** = ขั้น 1, 2, 4 เสร็จ → ยุบ (§2.4); ขั้น 3 ไม่ถูกนับ

### 2.2 มือถือ 375 (ตัวอย่าง: ขั้น 1 เสร็จ, ขั้นถัดไป = 2)
```
┌─────────────────────────────────────┐
│ เริ่มใช้กลุ่มนี้ใน 4 ขั้น                  │  <- h2
│ ทำแล้ว 1 จาก 4 ขั้น                     │  <- progress (ink-muted)
│                                       │
│ ✓ ขั้นที่ 1  ชวนเพื่อนเข้ากลุ่ม [เสร็จแล้ว] │  <- แถวย่อ: ไอคอนถูก + ป้ายข้อความ
│ ┌───────────────────────────────────┐ │
│ │ ขั้นที่ 2 · ขั้นถัดไป                │ │  <- แถวเด่น พื้น --accent-soft
│ │ ลงวันไม่ว่างของคุณ                  │ │
│ │ บอกว่าวันไหนคุณติด เพื่อนจะได้เห็น   │ │
│ │ [        ลงวันไม่ว่าง        ]       │ │  <- ปุ่มหลัก เต็มแถว สูง --tap
│ └───────────────────────────────────┘ │
│   ขั้นที่ 3  ดูวันที่ทุกคนว่างตรงกัน  ›  │  <- แถวรอ ทั้งแถวเป็นลิงก์
│   ขั้นที่ 4  สร้างนัด                ›  │
└─────────────────────────────────────┘
```
- ขั้นที่ไม่ใช่ "ถัดไป" แสดงเฉพาะ title (+ ป้ายเสร็จ) ไม่แสดง body/cta → การ์ดไม่สูงเกินไป
- ทุกแถวแตะได้ ≥ `--tap` สูง · ปลายทาง: ขั้น 1 → `settings#invite` · 2 → ฟอร์ม busy/ปฏิทิน · 3 → `/calendar?g=…&v=free` · 4 → ปุ่มสร้างนัดเดิม

### 2.4 ครบทุกขั้น (ยุบ)
```
┌─────────────────────────────────────┐
│ ✓ ครบทุกขั้นแล้ว · กลุ่มพร้อมใช้งาน   [ดูขั้นตอน] │  <- แถบบาง สูง ≈ --tap
└─────────────────────────────────────┘
```
- ปุ่ม `allDone.show`/`allDone.hide` สลับ (`aria-expanded` + `aria-controls`) · ขยายแล้วแสดงรายการ 4 ขั้นแบบแถวย่อทั้งหมด · ค่าเริ่มต้น = ยุบ · ไม่เก็บสถานะ
- ถ้าภายหลังไม่ครบ (นัดผ่านไป/สมาชิกออก) แถบกลับมาเด่นตามข้อมูลจริง

### 2.5 กลุ่มคนเดียว (solo) — ไม่ซ้ำกับการ์ด solo
- **ตัดการ์ด `group.solo` ออกจากหน้ากลุ่ม** ใช้แถบขั้นตอนอย่างเดียว: ขั้น 1 = "ขั้นถัดไป" และใช้ `group.steps.invite.soloBody` แทน `invite.body`
- ขั้น 3 และ 4 ยังเป็นแถวรอ (ลิงก์ได้) — ขั้น 3 จะไปเจอ `empty.calendarSolo` ที่ชี้กลับขั้น 1 ตรงลำดับอยู่แล้ว
- การ์ด `calendarLinks` เดิมไม่เกี่ยว ไม่แตะ

## 3. ป้ายสมาชิก (MemberList)
```
375:  [อวตาร] มะลิ                     สมาชิก
        └ [ยังไม่ได้ลงวันไม่ว่าง]          <- ป้ายใต้ชื่อ (wrap ได้)
768:  [อวตาร] มะลิ    สมาชิก   [ยังไม่ได้ลงวันไม่ว่าง]   ⋮
```
- pill เล็ก: พื้น `--warn`, ตัวอักษร `--warn-ink`, ขนาด `--text-sm` (≥ 14px) ไม่มีไอคอนเตือน ไม่ใช้สีแดง/`--busy`/`--danger` (ไม่กล่าวหา)
- แสดงเฉพาะสมาชิก **คนอื่น** ที่ `hasUpcomingBusy === false` · **ไม่แสดงบนแถว "คุณ"** (ขั้น 2 ของแถบพูดเรื่องเดียวกันอยู่แล้ว) · ถ้า field ไม่มีค่า = ไม่ป้าย
- a11y: เป็นข้อความจริง ไม่ใช่สีอย่างเดียว · ปุ่ม/แถวใช้ `rowAria` เดิม แล้วต่อ `noBusyAria` (หรือ `aria-describedby` ชี้ `noBusyHint` ที่ซ่อนด้วย sr-only) · `noBusyHint` ไว้เป็นคำอธิบายสำหรับ AT/tooltip เท่านั้น ไม่ต้องแสดงเป็นบรรทัดถาวร
- ที่ 375 ป้ายอยู่บรรทัดที่สองใต้ชื่อ ไม่ดันชื่อ/บทบาท

## 4. การ์ดแนะนำบนหน้าหลัก
```
375/768 (บนสุดของหน้าหลัก เหนือการ์ดนัดถัดไป/empty state)
┌─────────────────────────────────────┐
│ เริ่มใช้ maewmeet ใน 4 ขั้น             │
│ 1. สร้างกลุ่มหรือเข้ากลุ่มกับเพื่อน      │
│ 2. ทุกคนลงวันไม่ว่างของตัวเอง          │
│ 3. ดูว่าวันไหนทุกคนว่างตรงกัน         │
│ 4. สร้างนัดจากวันนั้น                 │
│ เปิดดูอีกครั้งได้ที่แท็บ “ฉัน”          │  <- ink-muted
│                    [ เข้าใจแล้ว ]      │  <- สูง --tap
└─────────────────────────────────────┘
```
- การ์ด `--surface` + `--line` เหมือนการ์ดอื่น · ไม่ใส่รูปแมวใหญ่ (ไม่ดันเนื้อหา) ถ้าใส่ใช้ `--cat-sm` มุมหัวการ์ด
- สถานะ: แสดง (ค่าเริ่มต้น / อ่าน localStorage ไม่ได้) · ปิดแล้ว (ไม่ render) · เปิดใหม่จาก `/me` = ล้าง flag แล้วไปหน้าหลัก
- อ่าน flag ฝั่ง client หลัง mount: ให้การ์ด fade เข้า `--dur-fast` เพื่อไม่กระพริบแรง
- a11y: `<section aria-labelledby>` + `<ol aria-label=listAria>` ตัวเลขจริง · หลังกด "เข้าใจแล้ว" ย้ายโฟกัสไปหัวหน้า (ไม่ให้โฟกัสหาย) · ไม่ใช้ `role="dialog"` (ไม่ขวางการใช้งาน)

## 5. ทางเข้าใน `/me`
แถวเดียวในส่วน "บัญชี" ใกล้ "ความเป็นส่วนตัว": ชื่อ `me.howTo` + คำอธิบายย่อ `me.howToHint` (ink-muted) + ลูกศร · สูง ≥ `--tap` · เป็นลิงก์ไปหน้าหลักพร้อมล้าง flag

## 6. Tokens และคอนทราสต์ (ไม่เพิ่ม token)
| ใช้กับ | token |
|---|---|
| การ์ด | `--surface`, `--line`, `--radius-lg`, `--ink`, `--ink-muted` |
| ขั้นถัดไป | พื้น `--accent-soft` + ตัว `--accent-soft-ink`; ปุ่ม `--accent`/`--on-accent`; ลิงก์ `--accent-ink` |
| ขั้นเสร็จ | `--free` + `--free-ink` (ป้าย "เสร็จแล้ว" + ไอคอนถูก) |
| ป้ายยังไม่ลง | `--warn` + `--warn-ink` |
| โฟกัส | `--focus` / `--focus-ring` |

ทุกคู่เป็นคู่ที่ตรวจใน CONTRAST.md/สคริปต์คอนทราสต์เดิมแล้ว — ผลที่รันรอบนี้อยู่ใน Handoff Certificate

## 7. a11y และการเคลื่อนไหว
- แถบ = `<section aria-labelledby=heading>` + `<ol aria-label=listAria>` · แต่ละ `<li>` มีข้อความ "ขั้นที่ N" ตามด้วยชื่อขั้นและสถานะเป็นข้อความ ("เสร็จแล้ว" / "ขั้นถัดไป")
- ขั้นถัดไปใส่ `aria-current="step"` · ขั้นเสร็จมีทั้งไอคอนและข้อความ ไม่ใช้สีอย่างเดียว
- ไม่ใช้ live region (สถานะเปลี่ยนเมื่อผู้ใช้กลับมาหน้านี้ ไม่ต้องประกาศ)
- Tab: ตามลำดับขั้น 1→4 · ห้ามลิงก์ซ้อนลิงก์ (แถวเป็นลิงก์ ปุ่ม cta ของขั้นถัดไปเป็นปุ่ม/ลิงก์แยกในการ์ดเด่น ไม่ซ้อนในแถวลิงก์)
- การเคลื่อนไหว: ยุบ/ขยายแถบ `--dur-fast` (150ms) + `--ease-out` ด้วย fade/ความสูงสั้นๆ · การ์ดแนะนำ fade `opacity 0→1` `--dur-fast` · `prefers-reduced-motion`: สลับทันทีไม่มีการเคลื่อนไหว
- 375/390/768: ไม่เลื่อนแนวนอน · TH/EN ยาวแล้ว wrap ได้ · ปุ่ม cta เต็มแถวบนมือถือ
