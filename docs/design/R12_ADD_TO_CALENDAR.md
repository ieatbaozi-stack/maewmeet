# R12 — เพิ่มนัดลงปฏิทิน (wireframe)

ผู้เขียน: ux · ที่มา: R12_CONTRACT §4 · คีย์ข้อความ: `appointments.calendar.*` และ `privacy.calendar.*` (TH/EN ใน `messages/*.json`)
ใช้ `Sheet` เดิมและ token เดิมทั้งหมด (สว่าง/มืด) ไม่เพิ่มสีใหม่ · ปุ่มและแถวที่กดได้สูง >= 44px · ข้อความทุกอย่างผ่าน i18n · UA ใช้จัดลำดับ/หน้าตาเท่านั้น

## 1. ปุ่มใต้ RsvpControl
แสดงเมื่อ: ตอบ "ไป" + บันทึกเสร็จ (`!saving`) + นัด active + ยังไม่จบ (§4.1) · เงื่อนไขอื่นไม่แสดงปุ่ม (ไม่ต้องมีที่ว่างค้าง)
```
 appt-rsvp-section
+--------------------------------------+
| คุณจะไปไหม                (question) |
| [  ไป  ] [ อาจไป ] [ ไม่ไป ]         |  RsvpControl เดิม
| บันทึกคำตอบแล้ว: ไป          (saved) |
|                                      |
| [ (ไอคอนปฏิทิน) เพิ่มลงปฏิทิน ]  add |  ปุ่มรอง (outline, ขอบ --line-control) กว้างเต็มแถว
+--------------------------------------+
```
- ปุ่มรอง ไม่แย่งกับ "ไป" · ไอคอนปฏิทินเส้นเรียบ 20px ซ้ายข้อความ (aria-hidden) · ระยะห่างจาก RsvpControl 12px
- ระหว่างบันทึก (`saving`) ปุ่มหาย ไม่ disabled ค้าง · เปลี่ยนเป็น "อาจไป/ไม่ไป" ปุ่มหาย
- กดแล้วเปิด sheet (focus เข้า sheet, ปิดแล้วโฟกัสกลับที่ปุ่ม)

## 2. Sheet (สถานะปกติ)
bottom sheet ครึ่งจอ มุมบนโค้ง 16 (ตาม UI_DIRECTION) ปัดลง/กดนอก/ปุ่มปิดเพื่อปิด
หัว `sheetTitle` · **`oneTime` อยู่ใต้หัวทันที เห็นก่อนกดตัวเลือก ไม่ซ่อนใน tooltip/พับ** (R12-12)

### 2.1 iPhone / iPad (.ics ก่อน)
```
+--------------------------------------+
| เพิ่มนัดนี้ลงปฏิทิน        (sheetTitle) [x]
| (i) เป็นการคัดลอกครั้งเดียว ...  oneTime|  กล่องข้อมูล พื้น --surface-2 ตัวอักษร --ink
|                                      |
| [ ปฏิทินในเครื่อง (ไฟล์ .ics)  >  ]  |  แถวที่ 1 = ปุ่มหลัก (เติมสีหลัก) <a href>
| [ Google Calendar              ^  ]  |  แถวที่ 2 = outline <a target=_blank>
|   ชื่อนัด เวลา สถานที่ และลิงก์นัด    |  googleNote ติดใต้แถว Google (12-13px, --ink-muted)
|   จะถูกส่งไปที่ Google               |
+--------------------------------------+
```
### 2.2 Android / อื่น ๆ (Google ก่อน)
```
| เพิ่มนัดนี้ลงปฏิทิน                [x]
| (i) oneTime
| [ Google Calendar              ^  ]  หลัก
|   googleNote
| [ ปฏิทินในเครื่อง (ไฟล์ .ics)  >  ]  outline
```
- `googleNote` ผูกกับแถว Google ด้วย `aria-describedby` และอยู่ติดกัน (ห่าง <= 4px) ไม่ไปรวมกับ `oneTime`
- แถวทั้งสองแสดงเสมอ ไม่ว่าตรวจ UA ถูกหรือผิด · ก่อนตรวจ UA เสร็จ (ตอน mount) ใช้ลำดับ "อื่น ๆ" ไม่กระพริบสลับหลังเปิด sheet เพราะตรวจตอนเปิด (client)
- กด `.ics` = นำทางด้วยลิงก์ธรรมดา ไม่มี spinner ใน sheet · sheet ปิดเองไม่จำเป็น (ผู้ใช้กลับมาจากตัวนำเข้าปฏิทิน) แนะนำคงเปิดไว้ให้ปิดเอง

## 3. Sheet ใน LINE in-app browser (UA มี `Line/`, §4.4)
ไม่แสดง 2 ตัวเลือก
```
+--------------------------------------+
| เพิ่มนัดนี้ลงปฏิทิน                [x]
| (i) oneTime
| เปิดในเบราว์เซอร์ก่อน แล้วค่อยเพิ่ม   |  lineHint
| ลงปฏิทิน                             |
| [ เปิดในเบราว์เซอร์ ]                |  ปุ่มหลัก ลิงก์ไป /appointments/<id>?openExternalBrowser=1
+--------------------------------------+
```

## 4. สถานะและกรณีขอบ
| สถานะ | ที่เห็น |
|---|---|
| ปกติ iPhone/Android | ข้อ 2.1 / 2.2 |
| LINE in-app | ข้อ 3 |
| ชื่อนัดยาว/สถานที่ยาว | ไม่แสดงในปุ่ม/sheet จึงไม่ล้น · ข้อความ `oneTime`/`googleNote` ขึ้นบรรทัดใหม่ได้ ไม่ตัดด้วย ellipsis |
| นัดยกเลิก/จบแล้ว/ตอบอื่น/ยังไม่ตอบ | ไม่มีปุ่ม จึงไม่มี sheet · ถ้า sheet เปิดค้างแล้วนัดกลายเป็นยกเลิก/จบ (poll) ให้ปิด sheet |
| เปิดลิงก์ `.ics` แล้วนัดยกเลิก/จบ/หมดสิทธิ์ | route เด้งกลับหน้านัด (303) หน้านัดแสดงสถานะยกเลิก/ผ่านไปแล้วเดิม ไม่ต้องมีข้อความใหม่ |
| ไม่มี loading/error ใน sheet | เป็นลิงก์นำทาง ไม่มี fetch จึงไม่มีสถานะรอ/ผิดพลาดในแอป |
| JS ยังไม่ทำงาน | ปุ่มไม่แสดง (ปุ่มเปิด sheet ต้องใช้ client) ยอมรับได้ เพราะหน้านัดทั้งหน้าพึ่ง client อยู่แล้ว |

## 6. ธีมและคอนทราสต์ (token เดิม ดู CONTRAST.md)
| ส่วน | สว่าง | มืด |
|---|---|---|
| พื้น sheet | `--surface-veil` บน `--surface` | เหมือนกัน (ค่ามืด) |
| `oneTime` กล่องข้อมูล | พื้น `--surface-2` ตัว `--ink` | พื้น `--surface-2` ตัว `--ink` |
| `googleNote` | ตัว `--ink-muted` | ตัว `--ink-muted` |
| ปุ่มหลัก / outline | สี/เส้นเดียวกับปุ่มหลัก/รองเดิมในแอป | เหมือนกัน |
ใช้คู่สีที่ผ่าน >= 4.5:1 อยู่แล้วใน CONTRAST.md เท่านั้น ห้ามใช้สีจางกว่า `--ink-muted` กับ `oneTime` และ `googleNote` เพราะเป็นข้อความที่ต้องอ่านก่อนตัดสินใจ

## 7. ภาพหน้าจอ 375/390/768
ยังไม่มีคอมโพเนนต์ให้เรนเดอร์ในรอบนี้ (ux ไม่เขียนคอมโพเนนต์) · ภาพหน้าจอ 375/390/768 × th/en × สว่าง/มืด จะถ่ายจากคอมโพเนนต์จริงของ frontend ในขั้น e2e/qa (R12-13)

## 8. คำที่ปรับจากร่าง contract §4.3
- `oneTime`: "เลื่อนหรือยกเลิกภายหลัง" → "ทีหลัง" และเติม "ของคุณ" · EN ใช้ "later" และ ’ ตัวโค้ง ตามคีย์เดิมของแอป
- `googleNote`: เพิ่ม "ลิงก์นัด" / "link" เพราะลิงก์นัดถูกส่งไป Google ด้วยจริง (contract §6) ร่างเดิมบอกไม่ครบ
- `privacy.calendar.body`: ระบุว่า Google ได้รับข้อมูลจากเบราว์เซอร์ผู้ใช้โดยตรง ไม่ผ่านเซิร์ฟเวอร์เรา · ไม่ส่งรายละเอียดนัด พิกัด ชื่อกลุ่ม ชื่อสมาชิก · ไฟล์ .ics อาจซิงก์ไปบัญชีผู้ใช้ · ลบจากแอปไม่หายจากปฏิทิน
- `privacy.updated`: 10 พ.ย. 2569 / 10 Nov 2026

## 9. สำหรับ frontend
- ต้องเพิ่ม `{ key: "calendar", items: ["body"] }` ใน `SECTIONS` ของ `/privacy` (คีย์ message มีแล้ว)
- ไอคอนปฏิทิน/ลูกศรออกนอกแอป: ใช้ไอคอนเส้นเรียบชุดเดิมของแอป ถ้าไม่มีให้แจ้ง ux
