# R6D — ตอบ "ไป" = ไม่ว่าง (ทิศทางให้ frontend)

ใช้ tokens เดิมทั้งหมด **ไม่เพิ่ม token ใหม่** (จึงไม่ต้องเพิ่มคู่ใน contrast.mjs เว้นแต่ใช้คู่สีใหม่) · ข้อความจาก `appointments.goingConfirm.*`, `appointments.conflict*`, `appointments.rsvp.goingHint`, `calendar.kind.*`, `busy.mine.going.*` (th/en)

## Popup ยืนยัน RSVP
- ใช้ `Sheet` เดิม (`src/components/shell/Sheet.tsx` — bottom sheet มือถือ / กล่องกลาง 768+) แบบเดียวกับ sheet ยกเลิกนัดใน `AppointmentDetail` · ห้ามทำ modal ใหม่ ห้ามซ้อน popup
- focus: เปิดแล้ว focus ไปที่ **ปุ่มยกเลิก/คงเดิม** (ปลอดภัยกว่า) ไม่ใช่ปุ่มยืนยัน · focus trap · Esc = ยกเลิก = คำตอบไม่เปลี่ยน · ปิดแล้วคืน focus ที่ปุ่ม RSVP เดิม · `role="dialog"` `aria-labelledby` = หัวข้อ
- **ไม่เลือกปุ่มยืนยันไว้ก่อน** (NN/g): สองปุ่มเท่ากันในลำดับเดียวกันทุกครั้ง — ปุ่มคงเดิมมาก่อน/อยู่บน (มือถือเรียงแนวตั้ง) ปุ่มยืนยันเป็นปุ่มหลัก `--accent` ข้อความเป็นผลลัพธ์ ไม่ใช้ "ใช่/ไม่" · ปุ่มสูง ≥ 44px
- ลำดับข้อความ (เป็น "ไป"): หัวข้อ `toTitle` → เนื้อความ `toBody` → (ถ้าชน) ส่วนชน → ปุ่ม · ถ้าชน: ปุ่มยืนยันเปลี่ยนเป็น `conflictConfirm` และเพิ่ม `conflictNote` เหนือปุ่ม (ไม่มี popup ที่สอง)
- ส่วนชน: กล่อง `--warn` / `--warn-ink` + ไอคอนเตือน (ไม่พึ่งสี) · หัวข้อ `conflictTitle` เป็น `<h3>` · รายการเป็น `<ul>` สูงสุด 5 แถว + `conflictMore` · ชื่อยาวตัด 2 บรรทัด (`line-clamp`) เวลาไม่ตัด · แถวนัดกลุ่มอื่นของตัวเองใช้ `conflictApptGroup`
- จาก "ไป": `fromTitle` + `fromBody` · ปุ่ม `fromKeep` (ก่อน) / `fromConfirm` (ใช้ `--accent` เช่นกัน ไม่ใช้สีอันตราย — ไม่ได้ทำลายข้อมูล)
- ระหว่างบันทึก: ปิดทั้งสองปุ่ม + ข้อความ `rsvp.saving` ใน `aria-live="polite"` · ล้มเหลว: ปิด sheet คืนค่าเดิม แสดง `rsvp.error` ที่ตัวควบคุม RSVP

## RSVP และป้ายชน
- `goingHint`: บรรทัด `small muted` ใต้ปุ่ม RSVP ผูก `aria-describedby` กับกลุ่มปุ่ม
- `conflictBadge`: ชิป `--warn`/`--warn-ink` + ไอคอนเตือน ขนาดข้อความ ≥ 12px · อยู่หน้านัด (ใต้หัวข้อ) และการ์ดในรายการ (บรรทัดสถานะ) · `conflictAria` ต่อท้าย aria ของแถว ห้ามโชว์ให้สมาชิกอื่นเห็น

## ปฏิทิน: 3 ชนิดช่วงที่ไม่ว่าง (แยกได้โดยไม่ใช้สีอย่างเดียว)
| ชนิด | พื้น | รูปร่าง/ไอคอน | ข้อความ |
|---|---|---|---|
| busy ปกติ | `--busy` + ลายเฉียง `--hatch` | ลายเฉียง | "ไม่ว่าง" หรือชื่อที่ลงไว้ + เวลา |
| นัดกลุ่มนี้ | `--event` / `--event-ink` | แคปซูล + ไอคอนปฏิทิน เส้นขอบทึบ | `kind.appointmentLabel` + เวลา · แตะไปหน้านัด |
| ติดนัดกลุ่มอื่น | `--surface-2` + ขอบ **ประ** `--line-control` | ไอคอนกุญแจ/ปิดบัง | `kind.otherLabel` + เวลา · **แตะไม่ได้** ไม่มี cursor pointer ไม่มี role=button |
- เดือน: จุดสมาชิกเหมือนเดิม (จุดมีรูปร่างตามชนิดไม่จำเป็น — รายละเอียดอยู่ในแผงวัน) · วัน: แถบ timeline ใช้ลาย/ขอบตามตาราง + รายการด้านล่างมีป้ายชนิดเป็นข้อความเสมอ
- `aria-label` ต่อรายการใช้ `kind.appointmentAria` / `kind.otherAria` (ชื่อ+เวลา) · ใต้ปฏิทินมีคำอธิบายชนิด (`kind.title` + 3 บรรทัด `busy/appointment/other`) ต่อจาก legend เดิม · เส้นประไม่ใช่ตัวแยกเดียว ต้องมีไอคอน+คำ
- ห้ามเดา/ใส่ชื่อนัด ชื่อกลุ่ม สถานที่ ใน DOM, `title=`, `aria-*` ของ `other_group_appointment` (ข้อมูลไม่มีมาให้อยู่แล้ว — ตรวจ DOM ในเทสต์)

## แท็บ "ของฉัน"
- ส่วนใหม่ใต้รายการ busy: หัวข้อ `busy.mine.going.title` + `lead` · แถว `row` ("{title} · {group}") + เวลา · ทั้งแถวเป็นลิงก์ไปหน้านัด (≥ 44px) `openAria` · ไม่มีปุ่มแก้/ลบ · บรรทัด `editNote` ท้ายส่วน · ว่าง: `empty`

## Anti-slop
ไม่ gradient / เงา (ใช้ขอบ `--line`) / อีโมจิ / แอนิเมชันเด้ง · sheet เปิดปิดแบบเดิม เคารพ `prefers-reduced-motion` · ไม่มี hex/px นอก tokens · ไม่มีคำชวนตกใจ (ไม่ใช้ "คำเตือน!") · ตรวจ 375/390/768 × th/en × สว่าง/มืด (ปุ่มยาวใน EN ไม่ล้น)
