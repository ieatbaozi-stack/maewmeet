## 2. Flow หลักบนมือถือ
สัญลักษณ์: `[ปุ่ม]` · `(sheet)` · `→` ไปต่อ · ข้อความในวงเล็บเหลี่ยมคือข้อความจริงบนปุ่ม

### F1 สมัคร / เข้าสู่ระบบด้วย PIN (U1, U14)
```
เปิดแอป (ยังไม่ล็อกอิน) → หน้า "เข้าสู่ระบบ"  [TH | EN มุมขวาบน]
  ├─ พิมพ์ชื่อผู้ใช้ → [ถัดไป] → แป้น PIN 6 จุด → ครบ 6 หลักส่งอัตโนมัติ
  │     ├─ ถูก → หน้าหลัก
  │     ├─ ผิด → "PIN หรือชื่อผู้ใช้ไม่ถูกต้อง เหลืออีก 3 ครั้ง" (จุดสั่นสั้น 1 ครั้ง ถ้าไม่ปิด motion)
  │     └─ ถูกล็อก → "ลองใหม่ได้ในอีก 5 นาที" + ลิงก์ [ลืม PIN]
  └─ [สร้างบัญชีใหม่] → ชื่อผู้ใช้ + ชื่อที่แสดง → ตั้ง PIN → ยืนยัน PIN อีกครั้ง
        ├─ PIN อ่อน (123456, 000000, 654321) → "PIN นี้เดาง่ายเกินไป ลองตัวเลขที่ไม่เรียงกัน"
        ├─ ชื่อผู้ใช้ซ้ำ → "ชื่อผู้ใช้นี้มีคนใช้แล้ว"
        └─ สำเร็จ → หน้าหลักสถานะว่าง (แมวโบกมือ) "ยังไม่มีกลุ่ม — สร้างกลุ่มหรือใส่โค้ดเชิญ"
```

### F2 ขอ reset PIN (U2, U3)
```
เข้าสู่ระบบ → [ลืม PIN] → พิมพ์ชื่อผู้ใช้ → [ส่งคำขอ]
  → "ส่งคำขอแล้ว ผู้ดูแลจะตรวจและอนุมัติ ระหว่างนี้ถ้านึก PIN เดิมออกก็เข้าได้ตามปกติ"   (ข้อความเดียวกันไม่ว่าชื่อมีจริงหรือไม่)
  ... super admin อนุมัติ ...
  → ผู้ใช้เข้าด้วย 123456 (ภายใน 24 ชม.) → บังคับหน้า "ตั้ง PIN ใหม่" (ไม่มีแถบล่าง ไม่มีปุ่มย้อน มีแค่ [ออกจากระบบ])
  → ตั้ง + ยืนยัน → "เปลี่ยน PIN แล้ว" → หน้าหลัก
  ถ้าเกิน 24 ชม. → "คำขอนี้หมดอายุแล้ว ส่งคำขอใหม่ได้เลย" [ส่งคำขอใหม่]
```

### F3 สร้างกลุ่ม + เชิญ (U4, U5)
```
แท็บ กลุ่ม → [สร้างกลุ่ม] (ปุ่มลอย) → (sheet: ชื่อกลุ่ม) → [สร้างกลุ่ม]
  → หน้ากลุ่ม (สมาชิก 1 คน) สถานะว่าง: แมวโผล่ขอบ "ยังมีแค่คุณในกลุ่มนี้" [ชวนเพื่อน]
  → (sheet ชวนเพื่อน)
       ├─ โค้ดเชิญ: "K7QM-3RXA" [คัดลอกโค้ด] [แชร์]  "หมดอายุ 22 ต.ค. 2569"
       └─ ชวนตรง: พิมพ์ชื่อผู้ใช้ → [ส่งคำเชิญ]
ฝั่งเพื่อน: แท็บ กลุ่ม → [ใส่โค้ดเชิญ] → พิมพ์ → [เข้ากลุ่ม] → เข้าทันที → หน้ากลุ่ม
   โค้ดผิด/หมดอายุ/ถูกยกเลิก → "ใช้โค้ดนี้ไม่ได้ ขอโค้ดใหม่จากเพื่อนในกลุ่ม"
```

### F4 ลง busy (U7)
```
แท็บ ปฏิทิน → [ลงวันไม่ว่าง] (ปุ่มลอย) → (sheet เกือบเต็มจอ)
  1. แตะวันเริ่ม → แตะวันจบ (ช่วงไฮไลต์ ข้ามเดือนได้ด้วยลูกศรเดือน)  "ส. 31 ต.ค. – อา. 1 พ.ย."
  2. สวิตช์ [ทั้งวัน] (เปิดอยู่) → ปิดแล้วโชว์ เวลาเริ่ม/จบ ทีละ 30 นาที
  3. ทำอะไร (ไม่ใส่ก็ได้): "เช่น ไปต่างจังหวัด, เข้าเวร"
  4. สวิตช์ [ไม่บอกรายละเอียด] → เพื่อนเห็นแค่ "ไม่ว่าง"
  ข้อความใต้ปุ่ม: "ทุกกลุ่มที่คุณอยู่จะเห็นช่วงนี้" (D5)
  [บันทึก] → sheet ปิด → ปฏิทินอัปเดตระดับความว่าง + แจ้งสั้น "บันทึกช่วงไม่ว่างแล้ว" [เลิกทำ]
```

### F5 ดูวันว่าง (U8, U9, U9.1)
```
แท็บ ปฏิทิน (กลุ่มล่าสุด · แตะชื่อกลุ่มเพื่อสลับ) → เดือนนี้ ช่องวันมีระดับ + "x/6"
  → แตะวัน → (sheet ครึ่งจอ)
       หัว: "เสาร์ 24 ตุลาคม 2569" / "ว่างครบ 6 จาก 6 คน"
       ช่วงที่ทุกคนว่างพร้อมกัน: [13:00–16:00 3 ชม.] [17:30–22:00 4 ชม. 30 นาที]  (แตะช่วง → เปิด F6 พร้อมเวลานั้น)
       ถ้าไม่ครบ: "ไม่มีช่วงที่ทุกคนว่าง" + รายชื่อคนที่ติด
       สมาชิก: ว่างทั้งวัน / ติด 08:00–13:00 ซ้อมดนตรี / ติด 09:00–12:00 ไม่บอกรายละเอียด
       [สร้างนัดวันนี้]
iPad: ไม่มี sheet — แผงขวาแสดงวันที่เลือกเสมอ
```

### F6 สร้างนัด (U10, U10.1)
```
จาก sheet วัน [สร้างนัดวันนี้] หรือแตะช่วงว่าง → (sheet ฟอร์ม เกือบเต็มจอ)
  ชื่อนัด* → วัน (เติมให้แล้ว แตะเปลี่ยนได้) → เวลาเริ่ม–จบ (เติมช่วงว่างแรกให้)
     ├─ อยู่ในช่วงว่าง → ✓ "อยู่ในช่วงที่ทุกคนว่าง (17:30–22:00)"
     └─ ทับ busy → แถบเตือนสีอำพัน "ปาล์มติดช่วง 08:00–13:00 ยังสร้างนัดได้" (ไม่บล็อก)
```

## 3. Wireframe ทุกหน้าหลัก × 4 สถานะ
แต่ละหน้า: **ปกติ** เป็น ASCII เต็ม · **โหลด / ว่าง / ผิดพลาด** เป็นส่วนที่ต่าง · กว้างอ้างอิง 375px · แถบล่าง `[ หน้าหลัก | ปฏิทิน | กลุ่ม | ฉัน ]` ทุกหน้าหลังล็อกอิน (ยกเว้นหน้าบังคับตั้ง PIN)

## 5. ผลตรวจตัวเอง (UX) ต่อหน้าตัวอย่าง — คำตัดสิน "เหมือนผลิตภัณฑ์จริงหรือเหมือนแม่แบบ AI?"
(ผู้ตรวจอิสระ QA ต้องตรวจซ้ำ — ส่วนนี้คือความเห็นของคนทำ)
- **หน้าหลัก** — *เหมือนผลิตภัณฑ์จริง*: จุดเด่นมีจุดเดียว (แถบนับถอยหลัง "อีก **2** วัน" สี `--event`) ที่เหลือเป็นข้อมูลเรียงแถวเรียบ ไม่มี gradient/เงาฟุ้ง/การ์ดซ้ำ 3 คอลัมน์ · ข้อมูลจริงรูปแบบยาก: ชื่อนัดยาวถูกตัด … ในแถว, นัดข้ามเดือน "ต.ค.–พ.ย.", นัดยกเลิกขีดฆ่า + ป้าย · ปุ่มตอบรับอยู่ในการ์ด ไม่ต้องเข้าไปอีกหน้า · จุดที่ยังเสี่ยง: ภาพรวมโทนครีม+คราม เป็นโทนที่พบบ่อย — ที่ทำให้ไม่เป็นแม่แบบคือเนื้อหาและการจัดลำดับ ไม่ใช่สี
- **ปฏิทิน + sheet วัน** — *เหมือนผลิตภัณฑ์จริง*: ปฏิทินเป็นพระเอก ระดับความว่างอ่านได้แม้ grayscale (ไอคอนถูก/ลายเฉียง/ตัวเลข) · sheet บอก "ช่วงที่ทุกคนว่าง" เป็นชิปที่แตะต่อได้ · มีกรณีซ่อนรายละเอียดและชื่อยาวมาก ("ณัฐพงศ์ วงศ์สวัสดิ์ศรีสกุล" ขึ้นบรรทัดที่ขอบคำ) · iPad ใช้สองคอลัมน์จริง ไม่ใช่ขยายมือถือ
- **สร้างนัด** — *เหมือนผลิตภัณฑ์จริง*: ฟอร์มเดียวปุ่มหลักเดียวติดล่าง, บอกผลต่อเพื่อน ("สมาชิกทั้ง 6 คนจะเห็นนัดนี้") และตรวจเวลาให้ทันที ("อยู่ในช่วงที่ทุกคนว่าง") · ค้นหาสถานที่แบบกดค้นหาตาม U10 · จุดที่ยังขาด: แผนที่ OSM ย่อ (โหลดไม่ได้ในสภาพแวดล้อมนี้ — ระบุไว้ใน W7)
- **ชุดแมว** — สม่ำเสมอเพราะสร้างจากชิ้นส่วนเดียวกัน ไม่ใช่ภาพ AI · ท่านอนมีรายละเอียดอุ้งเท้าที่ยังไม่เนียน (ควรเกลาในรอบ boss อนุมัติ)

### รอบ 2 (aurora) — คำตัดสินตรงไปตรงมา
- **หน้าเข้าสู่ระบบ** — *ดูเป็นผลิตภัณฑ์มืออาชีพ* โดยเฉพาะธีมมืด: ก้อนแสงครามด้านบนและชมพู/เขียวด้านล่างให้บรรยากาศแบบที่ boss ต้องการ โดยฟอร์มยังอ่านชัดในการ์ด veil · ธีมสว่างเป็นพาสเทลบางๆ สุภาพ ไม่หวือหวา
- **หน้าหลัก** — *ดีขึ้น* ธีมมืดมีมิติ การ์ดนัดถัดไปลอยเด่นบนแสง · ธีมสว่าง aurora จางกว่า เห็นเป็นแสงม่วง/เขียวอ่อนรอบการ์ด ไม่รบกวนการอ่าน
- **ปฏิทิน / สร้างนัด** — aurora ระดับ soft *แทบไม่เห็น* โดยเฉพาะธีมสว่างและตอนเปิด sheet (มี scrim) — ตั้งใจให้เป็นแบบนี้ ข้อมูลไม่รก · จุดที่ยังไม่สวย: (1) บน sheet ธีมสว่างเห็นรอยแสงม่วงจางทะลุ veil ที่ขอบขวาเล็กน้อย ถ้า boss ไม่ชอบ เพิ่ม `--surface-veil` เป็น .92 ได้ (2) ภาพ iPad ธีมสว่างมีเส้นวงไล่สีจางๆ (banding 8 บิต) มุมล่างซ้าย แก้ได้ด้วยการเพิ่ม `--aurora-blur` หรือใส่ noise บางๆ — ยังไม่แก้รอบนี้
- **ข้อเสนอ**: ถ้า boss อยากให้ aurora เด่นขึ้นในธีมสว่าง ทางที่ไม่ทำให้คอนทราสต์เสีย = เพิ่ม α เฉพาะก้อนที่อยู่ไกลจากข้อความหัวหน้า (ก้อนล่าง b3/b4) ไม่ใช่เพิ่มทุกก้อน

- จุดตัดเดียว 768px (48em) · ไม่มีค่าสี/ระยะนอก tokens (QA grep ได้ตามที่ทำใน Handoff)
