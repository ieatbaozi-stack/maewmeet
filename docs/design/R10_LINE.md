# R10 — ส่วนเชื่อม LINE ใน `/me` (wireframe)

ผู้เขียน: ux · ที่มา: R10_CONTRACT §2 · คีย์ข้อความ: `me.line.*` (TH/EN ใน `messages/*.json`)
วางเป็นการ์ดใหม่ระหว่าง "ความปลอดภัย" และ "บัญชี" ใช้ token เดิมของการ์ดใน `/me` (สว่าง/มืด) · ปุ่มสูง >= 44px · ข้อความทุกอย่างผ่าน i18n

## สถานะ
### 1. ยังไม่เชื่อม (default)
```
+--------------------------------+
| แจ้งเตือนทาง LINE      (title) |
| รับข้อความเตือนก่อนนัด...(hint)|
| [ เชื่อมต่อ LINE ]   (connect) |
+--------------------------------+
```
### 2. กำลังขอโค้ด
ปุ่ม connect disabled + แสดงสถานะกำลังโหลด (ใช้ `common` เดิมถ้ามี) ห้ามกดซ้ำ
### 3. แสดงโค้ด (หมดอายุ 10 นาที)
```
+--------------------------------+
| โค้ดเชื่อมต่อของคุณ (codeLabel)|
|      [  K7M2-QX9P  ]  (mono,   |
|       ตัวใหญ่ เลือกคัดลอกได้)   |
| เพิ่มเพื่อน “แมวเจอกัน” แล้ว    |
| ส่งโค้ดนี้ในแชท ... (codeHint) |
| [ เพิ่มเพื่อนใน LINE ] (addFriend)|
|  (QR บนจอใหญ่ >= 768; มือถือ    |
|   ใช้ปุ่มลิงก์ ไม่ต้องมี QR)    |
+--------------------------------+
```
- โค้ดใช้ตัวอักษรอ่านง่าย (ไม่มี 0/O 1/I) · aria-live=polite เมื่อโค้ดปรากฏ
- หมดอายุ: กลับเป็นสถานะ 1 (ผู้ใช้กดขอใหม่) · หน้าเช็กสถานะเป็นระยะหรือเมื่อโฟกัสกลับ แล้วสลับเป็นสถานะ 4 เองเมื่อเชื่อมสำเร็จ
### 4. เชื่อมแล้ว
```
+--------------------------------+
| แจ้งเตือนทาง LINE              |
| (o) เชื่อมต่อ LINE แล้ว        |
| [ ยกเลิกการเชื่อมต่อ ] (ปุ่มรอง)|
+--------------------------------+
```
กดยกเลิก -> dialog ยืนยัน (`disconnectConfirm`) ปุ่มยืนยัน = disconnect, ปุ่มยกเลิก = ใช้คำเดิมจาก `common`
### 5. ผิดพลาด
ข้อความ `me.line.error` ใต้ปุ่ม สี error (คอนทราสต์ >= 4.5:1) role=alert · ไม่ล้างสถานะเดิม
### 6. ช่องทางปิด (ไม่มี env LINE)
ซ่อนการ์ดทั้งใบ (contract §2: ปิดเงียบ)

## หมายเหตุ
- ข้อความ reply ใน LINE (`line.link.*`) และข้อความเตือน (`line.message.*`) อยู่ใน `messages/*.json` ฝั่งเซิร์ฟเวอร์เลือกตาม `user.locale`
- `/privacy` มีหัวข้อใหม่ `privacy.line.{title,body}` และ `privacy.retention.line` ต้องให้ frontend เรนเดอร์ (R10-9)
