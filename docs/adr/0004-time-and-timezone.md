# ADR 0004 — การเก็บเวลา, timezone และการแสดงปี พ.ศ.

- **Status**: Proposed (Architect, 2026-10-15) · แก้รอบ 2 (2026-10-16): **สัปดาห์เริ่มวันจันทร์** (boss ตัดสิน) — §5 `monthGrid`, §6, เทสต์ #17–#21
- **เกี่ยวข้อง**: [PRD D9, D10, U7, U8, U10, U11, U14](../prd/PRD.md) · [CLAUDE.md กฎ 9](../../CLAUDE.md) · [PROCESS ข้อ 10](../team/PROCESS.md) · [ADR 0001](0001-stack-and-project-structure.md) (temporal-polyfill) · [ADR 0005](0005-common-free-time-algorithm.md)
- **เจ้าของการ implement**: Calendar & Time (`src/lib/calendar/**`, `tests/calendar/**`)

## Context
PRD ให้เก็บ UTC + วันที่ท้องถิ่น + tz ต่อรายการ ดีฟอลต์ Asia/Bangkok (ไม่มี DST) แต่ต้องรองรับ tz อื่นเผื่อเที่ยวต่างประเทศ · busy มี 3 แบบ (หลายวัน / ทั้งวัน / ช่วงเวลาทีละ 30 นาที) · หน้าจอแสดง พ.ศ. แต่ข้อมูลเก็บ ค.ศ. · เวลาเป็นจุดเสี่ยงอันดับต้น

## Decision

### 1. ชนิดข้อมูลในฐาน (SQLite)
| ความหมาย | คอลัมน์ | ชนิด | ตัวอย่าง |
|---|---|---|---|
| ช่วงเวลาจริง (instant) | `*_at` | `INTEGER` epoch **milliseconds UTC** | `1735657200000` |
| วันที่ท้องถิ่น (ปฏิทิน ค.ศ.) | `local_*_date` | `TEXT` `YYYY-MM-DD` (เรียงตามสตริงได้) | `2024-12-31` |
| timezone | `tz` | `TEXT` ชื่อ IANA (ตรวจด้วย `Intl.supportedValuesOf('timeZone')`) | `Asia/Bangkok` |
| เวลาในวันของหน้าต่างกลุ่ม | `free_window_*_min` | `INTEGER` นาทีนับจากเที่ยงคืน `0..1440` | `480` = 08:00 |

ห้ามเก็บสตริงเวลาแบบมี offset, ห้ามเก็บ พ.ศ., ห้ามใช้ `Date` ของ JS คำนวณวัน (ใช้แค่ที่ขอบระบบผ่าน lib กลาง)

### 2. busy_block — ช่วงเป็นแบบ **ครึ่งเปิด** `[start, end)`
- **ช่วงเวลา (timed)** — รวม "หลายวันแบบมีเวลา" ด้วย: ผู้ใช้เลือกวันเริ่ม+เวลาเริ่ม และวันจบ+เวลาจบ ใน `tz` ของรายการ → **เป็นช่วงต่อเนื่องเดียว** (ไม่ใช่ "ทุกวัน 09–17") · แหล่งความจริง = `start_at`, `end_at` (UTC) · `local_start_date`/`local_end_date` = วันท้องถิ่นของจุดเริ่ม และของ `end − 1 ms` (เก็บเพื่อแสดงผล/ค้นหา) · กฎ: `end_at > start_at` (U7), เวลาท้องถิ่นทั้งสองปลายลงตัว 30 นาที, ยาวไม่เกิน 62 วัน
- **ทั้งวัน (all_day)** — รวม "หลายวันติดกัน": แหล่งความจริง = `local_start_date ≤ local_end_date` (รวมปลาย, U7: end ≥ start) เป็น **วันที่ลอย** (`PlainDate`) ไม่ผูก tz ตอนคำนวณ (ADR 0005) · `start_at`/`end_at` เก็บค่าที่คำนวณได้ = เที่ยงคืนต้นวันแรก และเที่ยงคืนหลังวันสุดท้าย ใน `tz` — ใช้แค่กรองช่วงตอน query
- `tz` ดีฟอลต์ `Asia/Bangkok` · v1 UI ไม่ต้องมีช่องเลือก tz (UX ตัดสิน) แต่ API/โมเดลรับได้

### 3. appointment
`start_at`, `end_at` (UTC, `end_at > start_at`) + `tz` (ดีฟอลต์ = tz กลุ่ม) + `local_date` (วันท้องถิ่นของจุดเริ่ม สำหรับจัดกลุ่มแสดงผล) · ความละเอียดเวลาไม่บังคับใน API (UX เลือกตัวเลือกทีละ 30 นาทีได้)

### 4. tz ของกลุ่ม
เพิ่ม `groups.tz` (ดีฟอลต์ `Asia/Bangkok`, v1 ไม่มี UI แก้) — หน้าต่าง 08:00–22:00 (D9) ตีความใน tz นี้ · ปฏิทินกลุ่มแสดงตาม tz นี้ · รายการที่ `tz` ต่างจากกลุ่มให้ UI แสดงป้าย tz กำกับ

### 5. API ของ `src/lib/calendar/**` (ห่อ temporal-polyfill — โค้ดอื่นห้ามเรียก Temporal ตรง)
```ts
// pseudo-code — สัญญาที่ Platform/Front-end ใช้
parseLocalDateTime(dateISO: string, timeHHmm: string, tz: string): EpochMs   // ปฏิเสธเวลาที่ไม่มีจริง (DST gap) ด้วย disambiguation:'reject'
toLocal(epochMs, tz): { date: 'YYYY-MM-DD'; minute: 0..1439 }
dayWindow(date, startMin, endMin, tz): [EpochMs, EpochMs]                    // endMin=1440 = เที่ยงคืนถัดไป
addDays(date, n) · compareDates(a, b) · eachDate(from, to)                     // PlainDate ล้วน (ปีอธิกสุรทินถูกเอง)
normalizeBusyInput(input): BusyRow                                             // ข้อ 2 ทั้งหมด + validation codes
todayIn(tz, nowMs): 'YYYY-MM-DD' · daysUntil(nowMs, startAtMs, tz): number    // U11 "อีกกี่วัน" นับเป็นวันปฏิทินใน tz ของนัด
format(epochMs | date, { locale: 'th'|'en', style, tz }): string             // ข้อ 6
WEEK_START = 1                                                                 // ISO: 1 = จันทร์ (boss 2026-10-16) — ทั้งสองภาษา ไม่ขึ้นกับ locale
startOfWeek(date): date                                                        // = date − (dayOfWeek − 1) วัน
monthGrid(year, month): { from: date; to: date; weeks: 4|5|6 }                 // จันทร์ก่อน/ตรงวันที่ 1 ถึงอาทิตย์หลัง/ตรงวันสุดท้าย (สัปดาห์เต็มเท่านั้น)
```
`now` ต้องถูก inject ได้ทุกฟังก์ชัน (เทสต์ใช้นาฬิกาจำลอง)

### 6. การแสดงผล (D10, U14)
- ใช้ `Intl.DateTimeFormat` เท่านั้น: ไทย = `th-TH-u-ca-buddhist` (ได้ พ.ศ. + ชื่อเดือนไทย), อังกฤษ = `en-GB` (ค.ศ.) · ทั้งสองภาษา `hourCycle: 'h23'` (24 ชม. — U14) · ตัวเลขอารบิก (`-u-nu-latn`) · ทดลองบน Node: `2026-10-15T03:30Z`, tz Bangkok → `วันพฤหัสบดีที่ 15 ตุลาคม พ.ศ. 2569 เวลา 10:30` / `Thursday, 15 October 2026 at 10:30`
- ข้อมูลเข้า**ไม่เคย**เป็น พ.ศ. — date picker ของเราส่ง ISO ค.ศ. เสมอ · API รับปีนอกช่วง 2000–2100 → `DATE_OUT_OF_RANGE` (กันการส่ง พ.ศ. มาผิด เช่น 2569)
- สูตร พ.ศ. = ค.ศ. + 543 ไม่ต้องเขียนเอง (Intl จัดการ)
- **สัปดาห์เริ่มวันจันทร์ทั้งสองภาษา** (boss 2026-10-16): หัวคอลัมน์ปฏิทิน จ อ พ พฤ ศ ส อา / Mon … Sun · ห้ามอ่านวันเริ่มสัปดาห์จาก locale ของเบราว์เซอร์ (`Intl.Locale#weekInfo` ของ `th`/`en-US` อาจให้วันอาทิตย์) — ใช้ `WEEK_START` ค่าคงที่
- หน้าจอเดือนขอข้อมูลด้วยช่วง `monthGrid()` (≤ 42 วัน ซึ่งไม่เกินเพดาน 62 วันของ API — ADR 0005) เพื่อให้วันของเดือนก่อน/ถัดไปที่โผล่ในตารางมีข้อมูล busy/วันว่างครบ

## Alternatives considered
| ทางเลือก | ทำไมไม่เลือก |
|---|---|
| เก็บเวลาเป็น ISO TEXT (`2024-12-31T15:00:00Z`) | อ่านง่ายแต่เปรียบเทียบ/บวกลบต้อง parse · INTEGER เทียบตรงใน SQL ได้และ index เล็กกว่า |
| busy ทั้งวันเก็บเป็นช่วง UTC อย่างเดียว | วันหยุด "วันที่ 1" ของคนกรุงเทพจะเลื่อนเป็นคนละวันเมื่อมองจาก tz อื่น — ผิดความหมายของ "ทั้งวัน" |
| busy หลายวันแบบมีเวลา = เวลาเดียวกันซ้ำทุกวัน | เป็น recurrence ซ่อนอยู่ ทำให้แก้/ลบ/คำนวณซับซ้อน และ PRD บอก "ช่วงหลายวัน = 1 รายการ" · ถ้า boss ต้องการแบบนี้ให้ทำเป็นฟีเจอร์ "ทำซ้ำ" ทีหลัง (ถามใน ARCHITECTURE §9) |
| เก็บเฉพาะ UTC ไม่เก็บ tz | แก้ไขรายการแล้วไม่รู้ว่าผู้ใช้ตั้งใจเวลาท้องถิ่นไหน · PRD สั่งให้เก็บ tz |
| ใช้ `toLocaleDateString` + บวก 543 เอง | ซ้ำซ้อนกับ Intl buddhist calendar และพลาดง่ายเรื่องชื่อเดือน/ลำดับ |

## Consequences
- + ขอบเขตทุกกรณี (ข้ามเที่ยงคืน/เดือน/ปี, ปีอธิกสุรทิน) เป็นงานของ Temporal ไม่ใช่โค้ดเรา
- + พร้อมสำหรับ tz อื่นโดยไม่ต้อง migrate
- − busy ทั้งวันกับ timed ใช้กฎต่างกัน (วันที่ลอย vs instant) — ต้องสื่อสารใน UI และเทสต์ให้ครบ
- − ต้องมี ESLint กัน `new Date()`/Temporal นอก lib กลาง (ADR 0001)
