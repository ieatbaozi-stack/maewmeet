## ข้อพบ (เรียงตามความรุนแรง)
1. **(กลาง · แก้แล้ว `7f3273e`) "ต่ออายุ" ชุดที่จบแล้วเปิดมาพร้อม error** — `src/components/busy/routine-model.ts` `formStateOfRoutine` (บรรทัด ~460–462): ชุดที่จบ (เช่น จบ 8 พ.ย. วันนี้ 11 พ.ย.) ตั้ง "ตั้งแต่" = สัปดาห์/เดือนนี้ แต่ "ถึง" = สัปดาห์/เดือนของวันจบเดิม (ก่อน "ตั้งแต่") → ช่อง select ทั้งสองแสดง "9–15 พ.ย. (สัปดาห์นี้)" เหมือนกัน แต่มีกรอบแดงทั้งสองช่อง + ข้อความ "วันสุดท้ายต้องไม่มาก่อนวันเริ่ม" + ไม่มีสรุป + ปุ่มบันทึกปิด ทั้งที่ผู้ใช้ยังไม่ทำอะไร (ภาพ `ext-th-mobile-375-1-open.png` ก่อนแก้) · ปุ่ม "ต่ออายุ" คือเส้นทางหลักของชุดที่จบแล้ว จึงเป็นประสบการณ์แรกที่ผู้ใช้เห็น · แก้: clamp "ถึง" ≥ "ตั้งแต่" · หลังแก้เปิดมาแล้วขึ้น "จะลง 3 วัน" ปุ่มเปิด · เพิ่มเทสต์ unit (สัปดาห์ + เดือน) · e2e เดิมไม่ครอบกรณีนี้ (ไม่มีเทสต์ต่ออายุชุดที่จบแล้ว) — แนะนำให้ test เพิ่ม 1 ข้อใน R14b ถ้ามีเวลา
2. **(ต่ำ) คู่มือ quickstart แถว "แก้" ไม่ตรงพฤติกรรม** — `docs/guides/quickstart-th.html` (section `more-routine-stop`, แถว "แก้"): เขียนว่า "ของฉัน → แตะแถวชุดนั้น → เลือก 'เฉพาะวันนี้' …" แต่จริง ๆ ตัวเลือก "เฉพาะวันนี้" ขึ้นเฉพาะเมื่อเปิดจากวันในปฏิทิน (แถวใน "ของฉัน" มีแค่ "ตั้งแต่…ไป"/"ทั้งหมด") และ tip ใต้ส่วนเดียวกันก็บอกตรงข้าม → ให้ secretary/ops แก้ข้อความ (ไม่ได้แก้เอง — เอกสารอยู่นอกขอบเขต qa)
3. **(ต่ำ/UX) ส่วนท้าย sheet ใช้พื้นที่มาก ที่ 375** — ท้าย sheet (D5 3 บรรทัด + ปุ่มบันทึก) กิน ~ 25–30% ของความสูงจอ ทำให้เห็นเนื้อฟอร์มครั้งละประมาณครึ่งจอ (ภาพ th/light 375) · ไม่ผิดตามดีไซน์ (ปุ่มบันทึกติดล่าง) แต่ถ้าเอา `visibilityHide` (บรรทัดที่ 3) ไปไว้ในเนื้อฟอร์มจะได้พื้นที่คืน — ข้อเสนอให้ ux พิจารณา
4. **(ต่ำ/ข้อความ) ข้อความ error ตอน *แก้* ยังพูดว่า "ยังไม่ได้ลงสักวัน / None of these days were added"** (RATE_LIMITED, CONFLICT ในโหมดแก้) ทั้งที่ไม่ได้ลงอะไรใหม่ — ux รับไว้แล้วใน design §8.2 ("CONFLICT → error.save … ยอมรับ") จึงไม่นับเป็นข้อบกพร่อง บันทึกไว้เฉย ๆ
5. **(ต่ำ) คอมเมนต์ JSDoc ตกค้าง** `routine-model.ts` ~บรรทัด 314 ("เดือน ตามภาษา …") ซ้อนอยู่เหนือคอมเมนต์ของ `timeRangeText` ไม่ได้ติดกับ `monthLabel` — ไม่กระทบการทำงาน
6. **(ข้อมูล) e2e ครอบแค่ 2 combo ต่อสเปก** (th/light, en/dark) ตามที่ออกแบบ — combo th/dark และ en/light ผมครอบด้วยสคริปต์ภาพ+วัดของตัวเอง (ไม่ commit) ผ่านหมด
