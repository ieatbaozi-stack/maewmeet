## 1. R15a — สิ่งที่ผู้ใช้เห็น (migration `0006`)
### 1.1 เว้นบางวันของแบบประจำ (feedback boss)
- การ์ดแบบประจำในรายการ "ของฉัน" มีปุ่ม **"เว้นบางวัน"** → เปิดปฏิทินเล็กของวันในชุดที่ยังไม่ผ่าน → เลือกได้หลายวัน → ยืนยันครั้งเดียว
- วันที่ถูกเว้นหายจากปฏิทินทุกกลุ่ม และไม่ฟื้นเมื่อแก้ทั้งชุด (ใช้ `busy_routine_skip` เดิม)
- ยกเลิกการเว้นได้ (เอาวันกลับ) ถ้าวันนั้นยังไม่ผ่าน
- platform: endpoint เว้น/คืนหลายวันในคำขอเดียว (≤ 31 วันต่อคำขอ, เจ้าของเท่านั้น, transaction เดียว, ใช้ rate limit `busy:routine`)

### 1.2 ไอคอนของกลุ่ม (feedback ผู้ใช้)
- ผู้ดูแลกลุ่ม (owner/admin) เลือกไอคอนให้กลุ่มจากชุดสำเร็จรูป (B1) เช่น อาหาร/บุฟเฟ่ต์, แบดมินตัน, ฟุตบอล, กาแฟ, เกม, ดนตรี, เดินทาง, ทำงาน, เรียน, บ้าน, แมว, หัวใจ ฯลฯ (ux คัด ~24 แบบ สไตล์เดียวกับแอป สว่าง/มืด)
- แสดงที่: หัวปฏิทิน/ตัวเลือกกลุ่ม, การ์ดในหน้ากลุ่ม, หน้าหลัก · ไม่ตั้ง = ไอคอนเริ่มต้น (แมว)
- ตรวจสิทธิ์ที่เซิร์ฟเวอร์ (rule 6) · รับเฉพาะคีย์ในรายการ (allowlist) ไม่รับรูป/URL
- schema: `groups.icon text NULL` (migration `0006` เพิ่มอย่างเดียว)

### 1.3 เปิดเหมือนแอปบน iPhone (feedback ผู้ใช้)

- quickstart เพิ่มวิธี "เพิ่มไปยังหน้าจอโฮม"

## 2. ไม่ทำในรอบนี้ (เสนอรอบหลัง — B9)
CSP แบบ nonce (เลิก `unsafe-inline`) · retention ลบถาวรกลุ่ม/คำเชิญที่ลบ + กู้กลุ่ม/บัญชีที่ลบ (ต้องตัดสินนโยบาย PDPA) · rate limit ฝั่งอ่านแบบ global · หน้า auth ตอบ 200 ระหว่าง stream · ลด e2e retries เป็น 0 · Server-Timing บนหน้า RSC · DST day strip (แอปใช้ Bangkok อย่างเดียว ยังไม่เกิด)

## 3. R15b — ความเร็ว (เฉพาะแบบไม่เสี่ยง ตามที่ boss สั่ง)
ตอนนี้ RSVP ใช้ 10 query (R11 เพิ่ม 1 จากที่ R7 ลดไว้ 9)
- **ทำ:** รวม `listMembers` + `listCurrentRsvps` ใน `toDetailDto` เป็น query เดียว (อ่านอย่างเดียว ได้ทั้ง RSVP และหน้ารายละเอียดนัด) −1 · ทางแจ้งเตือน: ใช้ชื่อจาก session ที่โหลดมาแล้ว และรวมเช็ก "ผู้สร้างยังเป็นสมาชิก" เข้า query สิทธิ์ −2 (เฉพาะตอนคำตอบเปลี่ยน) · `/groups/[gid]` ผ่านด่านกลุ่มครั้งเดียว −1
- **ไม่ทำ:** ย้ายการอ่านคำตอบเดิมออกนอก transaction (มีโอกาสแจ้งเตือนเกิน/ขาด 1 ครั้งเมื่อกดพร้อมกัน = มีความเสี่ยง) · ย้าย rate limit เข้า transaction · ย่อ DTO (เปลี่ยนรูป API)
- เกณฑ์: ผลลัพธ์ JSON เท่าเดิมทุกไบต์ (เทสต์เทียบก่อน-หลัง) · จำนวน query ลดตามที่ระบุ (`r7-baseline` ล็อกค่าใหม่) · ไม่มีเทสต์เดิมต้องเปลี่ยนความหมาย · ถ้าข้อไหนทำแล้วผลไม่เท่าเดิม ให้ทิ้งข้อนั้น

## 4. R15b — hardening เล็ก (ไม่มี migration)
- rate limit: PATCH busy · PATCH แบบประจำที่ได้ 404 ก็นับ (R14 Info 1) · ออก/เข้ากลุ่มซ้ำ (R10 Info 7)
- `?scope=` ซ้ำ → ปฏิเสธ 400
- LINE: ข้อความชื่อนัด/ชื่อกลุ่มทำให้ลิงก์กดไม่ได้ (R10 L1/L4) · เพดานรวมของ OA ต่อเดือน (B6)
- ชื่อ super admin ที่ไม่ใช่สมาชิกในกระดิ่งของกลุ่ม → ป้ายกลาง "ผู้ดูแลระบบ" (B7)
- `/api/prefs` บันทึก `user.locale` ด้วยตอนสลับภาษา (ป้ายในปฏิทิน/แจ้งเตือนใช้ภาษาถูก)
- ลิงก์แผนที่: คงรับทุก https (B5)
- เทสต์: config Vitest ถาวรข้าม EPERM ตอนลบ temp DB บน Windows · เทสต์ "นำทางเร็วไม่กระพริบ" ใช้เวลาจริง
- ops: CI ข้าม e2e เมื่อ PR แก้แค่เอกสาร (paths-ignore) · เปลี่ยนตัวอย่าง username `boss` ใน OPERATIONS
- NEXT_PHASE.md + PROGRESS ให้ตรงของจริง (secretary)
