## 1. สิ่งที่เปลี่ยน
### 1.1 ช่องสถานที่ในฟอร์มนัด
ก่อน: ช่องชื่อ + ปุ่ม [ค้นหา] (OpenStreetMap) · ลิงก์ซ่อนอยู่หลัง "วางลิงก์หรือพิกัด"
หลัง:

| ส่วน | รายละเอียด |
|---|---|
| ชื่อสถานที่ | ช่องพิมพ์ธรรมดา ไม่บังคับ ≤ 120 ตัว (เหมือนเดิม) |
| ลิงก์แผนที่ | ช่องวางลิงก์ **เห็นตลอด** ไม่ต้องกดเปิด · ไม่บังคับ · ตรวจด้วย `parseLocationInput` เดิม (รับลิงก์ https และพิกัดเหมือนเดิม) |
| คำแนะนำ | ใต้ช่องลิงก์ บอกว่าเปิดแอปแผนที่ ค้นหาสถานที่ แล้วกดแชร์ → คัดลอกลิงก์มาวาง |
| ปุ่มเปิดแอปแผนที่ | iPhone/iPad/Mac: **Apple Maps** และ **Google Maps** · เครื่องอื่น (Android, Windows, ไม่รู้): **Google Maps** อย่างเดียว · ถ้าพิมพ์ชื่อไว้ เปิดหน้าค้นหาชื่อนั้น ไม่มีชื่อ = เปิดหน้าแรกของแผนที่ |

- ปุ่มเป็นลิงก์ `https` ธรรมดา เปิดแท็บใหม่ (`noopener noreferrer`) · Google: `https://www.google.com/maps/search/?api=1&query=<ชื่อ>` · Apple: `https://maps.apple.com/?q=<ชื่อ>` · encode ชื่อเสมอ
- แยกชนิดเครื่องที่ client จาก user agent เท่านั้น ไม่ส่งไปเซิร์ฟเวอร์ · ตอน server render ยังไม่รู้เครื่อง ให้แสดง Google Maps ก่อนแล้วเพิ่ม Apple Maps หลัง hydrate (ไม่เกิด hydration mismatch)
- ชื่อสถานที่ถูกส่งไป Google/Apple **เฉพาะตอนผู้ใช้กดปุ่ม** · ไม่เรียก API ของ Google/Apple
- ไม่มีชิป "เลือกแล้ว" แบบเดิม: ชื่อกับลิงก์เป็นสองช่องแก้ได้อิสระ · แก้นัดเก่าที่มีพิกัดแต่ไม่มีลิงก์ ให้ช่องลิงก์แสดงพิกัดเป็น `lat,lng` และบันทึกกลับได้ค่าเดิม

### 1.2 หน้ารายละเอียดนัด (การ์ดสถานที่)
- เอาภาพแผนที่ OpenStreetMap ออก (B1)
- มีลิงก์ `https`: ปุ่ม "เปิดลิงก์แผนที่ (host)" แบบเดิม
- มีแต่พิกัด (นัดเก่าที่เลือกจากการค้นหา): ปุ่มเปิดในแอปแผนที่แบบ `geo:` เดิม
- มีแต่ชื่อ: ปุ่มค้นหาชื่อนั้นใน Google Maps / Apple Maps ตามกติกาเครื่องใน §1.1
- แก้ปุ่มที่ตัดสองบรรทัดและข้อความชิดขอบบนที่จอ 375 (backlog จาก qa R12.1) ในรอบนี้ด้วย

### 1.3 เอาการค้นหาสถานที่ออก
- ลบ `/api/places/search`, service `places.ts`, repo `place-search.ts`, `place-fetch.ts`, `PlaceMap.tsx` และ `tileGrid` ที่ไม่มีใครใช้แล้ว · ลบออกจาก `ROUTE_MANIFEST` และเทสต์ที่ล็อกรายการ route
- ลบ env `PLACE_SEARCH_ENABLED`, `NOMINATIM_BASE_URL`, `NOMINATIM_CONTACT`, `NEXT_PUBLIC_MAP_TILE_URL`, `NEXT_PUBLIC_MAP_ATTRIBUTION` จาก `env.ts` และ `.env.example` · เอา `tile.openstreetmap.org` ออกจาก CSP
- ตาราง `place_search_cache` **คงไว้ก่อน** ไม่มีโค้ดอ่าน/เขียน (B3) · นัดเก่าที่มีลิงก์ OSM หรือพิกัดยังแสดงได้
- ข้อความ `places.search.*` และ `privacy` ส่วน OpenStreetMap ที่ไม่ใช้แล้วให้ลบ ห้ามเหลือคีย์ค้าง

### 1.4 ลิงก์ในปฏิทินในเครื่อง (แก้ R12.1 §1.2)
| ปลายทาง | ตอนนี้ | หลัง R13 |
|---|---|---|
| `.ics` `URL` | ลิงก์นัด | **ลิงก์แผนที่** ถ้ามี `https` · ไม่มี = ลิงก์นัดเหมือนเดิม |
| `.ics` `LOCATION` | ชื่อสถานที่ | ชื่อสถานที่ (เหมือนเดิม) |
| `.ics` `DESCRIPTION` | `<mapUrl>\n<ลิงก์นัด>` | `แผนที่: <mapUrl>\nดูนัดในแมวเจอกัน: <ลิงก์นัด>` · ไม่มีลิงก์แผนที่ = บรรทัดลิงก์นัดบรรทัดเดียว (มีป้าย) |
| Google `details` | `<mapUrl>` ขึ้นบรรทัด `<ลิงก์นัด>` | ป้ายแบบเดียวกับ `.ics` |
| Google `location` | ชื่อสถานที่ | ชื่อสถานที่ (เหมือนเดิม) |

- ป้ายใช้ภาษาที่ผู้ใช้ตั้งไว้ในบัญชี (TH/EN) ตอนดาวน์โหลด ไม่มีค่า = ไทย · คำจริง ux เลือก ข้างบนเป็นตัวอย่าง · ห้าม hard-code ป้ายใน `ics.ts`: ส่งเข้ามาเป็นพารามิเตอร์จาก messages
- คาดว่า iPhone จะแสดงแถว `maps.app.goo.gl` + ปุ่ม Open ในส่วน Location แทนแถว `maewmeet.vercel.app` · Apple ไม่มีเอกสาร ต้องดูบนเครื่องจริง (T3) · ถ้าแย่กว่าเดิมให้กลับไปใส่ลิงก์นัดใน `URL` โดยคงป้ายไว้
- กฎ escape / fold 75 octet / https เท่านั้น / CRLF ไม่สร้างบรรทัดใหม่ / เขตเวลา ของ R12.1 คงเดิมทั้งหมด

### 1.5 หน้า `/privacy`
- ลบส่วนการค้นหาและภาพแผนที่ OpenStreetMap
- เพิ่ม: ปุ่มเปิด Google Maps / Apple Maps ส่งชื่อสถานที่ที่พิมพ์ไปที่ผู้ให้บริการนั้นเมื่อกดเท่านั้น
- ส่วนปฏิทินให้ตรง §1.4 · `privacy.updated` ตรงวันที่แก้
